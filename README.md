# 🎥 Video to ASCII in Terminal

This Python script converts videos into ASCII art and plays them directly inside your terminal.  
It uses **OpenCV** and **NumPy** to process each frame and display it as ASCII characters in real time.

---

## ✨ Features
- Converts video frames into ASCII art
- Plays videos inside the terminal
- Adjustable terminal width
- Adjustable FPS (or use the video’s original FPS)
- Works on Windows, macOS, and Linux

---

Make sure you have Python 3.7+ installed.
